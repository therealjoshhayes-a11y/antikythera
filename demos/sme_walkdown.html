Scope and rule definitions

Acceptance exit: After 3 panel ACCEPT decisions, finish immediately.

Rejection exit: After 4 panel REJECT decisions, finish immediately. This is a decision-count rule, not a minimum cosine-similarity score.

Queue exhaustion: If there are no unreviewed candidates left in any measure, finish and record that outcome.

Ranking: The three measures remain independent; scores are shown as context only and are never averaged or used as an acceptance threshold. This small offline demo does not compute embeddings or parse catalogs.

Provenance: Demonstrates the user-reported 3-accept / 4-rejection module behavior. It is separate from the currently published MinK v3.2 specification, which uses a configurable acceptance target and does not describe a rejection-count exit. This demonstration does not establish institutional approval.
